# Architecture Sub-Role: Intake & Discovery Interview

Consolidated from `intake-manager`.

## Responsibilities & Standards
- Rapidly clarify scope, technology choices, deployment targets, and user goals in a concise, structured manner.

## Intake Checklist
- [ ] Classification: Classify request type (`new-greenfield`, `feature-addition`, `targeted-fix`, `performance-optimization`, `refactor`).
- [ ] Tech Stack Confirmation: Confirm frontend framework (e.g. Next.js, Vite/React), backend (Node/Express, Fastify, Python), and database (Postgres, MongoDB).
- [ ] External Integrations: Identify third-party APIs (Stripe, Auth0, OpenAI, AWS S3) and authentication models.
- [ ] Deliverable Scope: Define the minimum viable vertical slice that delivers verifiable business value.
- [ ] Avoid Prose Bloat: Summarize requirements directly into executable contracts and testable user stories, not long-winded essays.
